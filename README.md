# .NET Core ile Kurumsal Uygulama Geliştirme Eğitimi

.NET Core, Microsoft tarafından geliştirilen, Windows, Linux ve macOS üzerinde çalışabilen modern, açık kaynak ve yüksek performanslı bir yazılım geliştirme platformudur.

Bu bootcamp içerisinde C# programlama dili ile başlayarak ASP.NET Core MVC, Web API, Entity Framework Core, SQL Server, katmanlı mimari, authentication, validation, deployment ve ReactJS ile full stack uygulama geliştirme süreçleri öğretilmektedir.

Katılımcılar gerçek proje mantığı ile:

- C# programlama
- Nesne yönelimli programlama
- ASP.NET Core MVC
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- LINQ
- Katmanlı mimari
- Authentication ve Authorization
- REST API
- ReactJS frontend geliştirme
- Kurumsal yazılım geliştirme

konularında uygulamalı çalışma yapar.
